# TOOLS.md - Local Notes

Skills define _how_ tools work. This file is for _your_ specifics — the stuff
unique to your setup: SSH hosts, device nicknames, preferred TTS voices, camera
names, hardware quirks.

## Examples

```markdown
### SSH
- home-server → 192.0.2.10, user: admin

### TTS
- Preferred voice: "Nova"

### Kitchen appliances
- Air fryer runs ~15-20°C hotter than recipes assume; check early.
```

Add whatever helps the assistant do its job. This is its cheat sheet for your world.
